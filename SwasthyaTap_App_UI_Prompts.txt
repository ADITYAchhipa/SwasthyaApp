================================================================================
                              DESIGN SYSTEM NOTES
================================================================================

TYPOGRAPHY:
- Headlines: Inter Bold, 24-28px
- Body: Inter Regular, 14-16px
- Captions: Inter Medium, 12px
- Indic scripts: Noto Sans [Language], matching weights

SPACING:
- Page padding: 16-24px
- Card padding: 16px
- Card border-radius: 12-16px
- Between sections: 24px

COLORS:
- Primary: #0F766E (Teal 700)
- Primary Light: #CCFBF1 (Teal 100)
- Accent: #F59E0B (Amber 500)
- Emergency: #DC2626 (Red 600)
- Hospital Blue: #1E40AF
- Background: #F8FAFC
- Card: #FFFFFF
- Text Primary: #1E293B
- Text Secondary: #64748B
- Success: #16A34A
- Border: #E2E8F0

ANIMATIONS:
- Page transitions: slide + fade (300ms ease)
- Card press: scale(0.98) + shadow reduce (150ms)
- NFC pulse: radial ripple (1.5s loop)
- Loading: skeleton shimmer
- Success: checkmark draw + confetti burst

ACCESSIBILITY:
- Minimum touch target: 44x44px
- Color contrast: WCAG 2.1 AA minimum
- Screen reader labels on all interactive elements
- Font scaling support (up to 200%)
- RTL support for Urdu

PLATFORMS:
- React Native / Flutter (cross-platform)
- iOS 14+ and Android 8+
- Responsive: 320px to 428px width
- Safe area support for notch/dynamic island
